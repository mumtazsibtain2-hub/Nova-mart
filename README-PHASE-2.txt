INSTALL
1. Keep Apache/MySQL running in D:\xampp.
2. Replace D:\xampp\htdocs\lumea-beauty with this updated folder OR copy over the old Phase 1 folder and choose Replace files.
3. DO NOT re-import the SQL if your current database already works.
4. Open http://localhost/lumea-beauty/

TEST
- Search: type serum, lipstick, Maybelline, cleanser, etc.
- Newsletter: submit an email in the footer. Check phpMyAdmin > lumea_beauty > newsletter_subscribers.
- Mobile: resize browser or test at 375px/576px/768px.
